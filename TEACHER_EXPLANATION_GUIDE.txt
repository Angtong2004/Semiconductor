--------------------------------------------------------------------------------
2. HOW THE METROLOGY DATA IS STRUCTURED
--------------------------------------------------------------------------------
Explain the physical parameters:

"Instead of simple random numbers, each sample represents an individual die
on a 300 mm silicon wafer with measurements from 4 standard cleanroom tools:

1. Spectroscopic Ellipsometry / Reflectometry:
   - Measures film thickness (t), refractive index (n at 633 nm), and optical
     phase delta.
   - For example, if target oxide thickness is 100 nm, an under-etched die
     shows 125 nm, while an over-etched die drops to 55 nm.

2. Atomic Force Microscopy (AFM) Surface Topography:
   - Measures average roughness (Ra), peak-to-valley height (Rz), and surface
     skewness (Ssk).
   - This is critical: positive skewness means upward spikes (dust/particles),
     while negative skewness means downward trenches or pits (scratches/etch damage).

3. Four-Point Probe & C-V Electrical Metrology:
   - Measures sheet resistance (Rs), gate breakdown field (Ebd), and dielectric
     leakage current.
   - Catches electrical shorts or thinned dielectric barriers.

4. CD-SEM & Defect Inspection:
   - Measures Critical Dimension deviation (CD bias) and defect aspect ratio."


--------------------------------------------------------------------------------
3. HOW THE MACHINE LEARNING MODEL WORKS (STEP-BY-STEP)
--------------------------------------------------------------------------------
Explain this technical flow:

Step 1: Domain Feature Engineering
"Before passing raw values into the model, I engineered 4 domain physics ratios:
 - UV-to-Visible Reflectance Ratio: tracks dielectric absorption changes.
 - AFM Peak-to-Roughness Aspect (Rz / Ra): distinguishes isolated sharp dust
   spikes from general surface roughness.
 - Dielectric Reliability Index (Breakdown field / Leakage current).
 - Thickness-to-CD Coupling: correlates lithography CD changes with etch depth."

Step 2: Preprocessing and Scaling
"I used RobustScaler rather than standard z-score normalization. This is because
cleanroom metrology features like particulate heights and leakage currents have
extreme heavy tails and outliers. RobustScaler uses median and interquartile range
(IQR), so outlier spikes do not distort the feature distribution.
Crucially, the scaler was fitted strictly on the training set to prevent data leakage."

Step 3: The Model Architecture (Random Forest Classifier)
"The champion model is a Random Forest with 150 decision trees.
Here is how it works under the hood:
 - Each tree is trained on a random bootstrap sample of the dies.
 - At each split node, the tree evaluates a random subset of metrology features
   and finds the threshold that maximizes information gain (minimizes Gini impurity).
 - For example, one tree might first split on 'film_thickness < 80 nm' to isolate
   over-etching, then split on 'surface_skewness < -1.5' to confirm CMP scratches.
 - When classifying an unknown die, all 150 trees vote. The class with the highest
   fraction of votes becomes the prediction, and that fraction gives us the
   confidence score (e.g., 96% confidence)."

Step 4: Handling Class Imbalance
"In real cleanrooms, 60% to 70% of dies pass specification, while defects are rare.
To mirror this, my dataset has a 64% nominal pass rate. I addressed this by setting
'class_weight=balanced' in the model, penalizing errors on rare defect classes
more heavily so the model does not ignore them."

5. LIKELY QUESTIONS YOUR TEACHER WILL ASK & EXACT ANSWERS
--------------------------------------------------------------------------------

Q1: "Why use Machine Learning? Why not just write simple IF-ELSE thresholds?"
Answer:
"Simple thresholds fail when defects overlap or multiple parameters drift
simultaneously. For instance, both an over-etched die and a CMP scratch have
reduced film thickness. A simple IF statement on thickness cannot tell them
apart. The ML model learns the multi-dimensional correlation: thickness + AFM
skewness + electrical breakdown. It detects non-linear boundaries that manual
rules miss."

Q2: "Why did you choose Random Forest instead of a Deep Neural Network?"
Answer:
"First, tabular metrology data with physical features is well-known in literature
to perform best with tree ensembles like Random Forest and XGBoost.
Second, Random Forest gives complete feature explainability (Mean Decrease in
Impurity), showing exactly which tool contributed most to the decision.
Third, it trains in under 2 seconds and evaluates a die in under 2 milliseconds,
making it fast enough to sit directly on an in-line tool controller in the fab."

Q3: "How do you know the model didn't just overfit?"
Answer:
"I split the data into 65% training, 15% validation, and 20% held-out test set
using stratified sampling to preserve class ratios. The preprocessor was fitted
only on the training split. I tested Random Forest, XGBoost, Support Vector
Machines, and an MLP Neural Network, and verified generalization on the held-out
test set using Balanced Accuracy and Macro F1 score."

Q4: "What metrology parameter turned out to be the most important?"
Answer:
"According to the feature importance analysis:
 1. Film thickness (10.0%) from Ellipsometry, which separates deposition and
    etching excursions.
 2. Optical phase delta (8.3%), which confirms thin-film path length.
 3. AFM surface skewness (7.7%), which separates protrusion spikes from scratch
    grooves.
 4. Sheet resistance (7.5%), which confirms conductive layer continuity."
